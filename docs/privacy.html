개인정보처리방침

시행일 2026년 11월 5일

1. 적용 범위

이 방침은 blank 데스크톱 앱과 공식 사이트(purplemacaron.github.io/blank)에 적용됩니다. blank는 별도의 계정 서버나 사용자 데이터베이스를 운영하지 않습니다.

2. 수집하지 않는 정보

blank는 이름, 이메일, 전화번호 같은 계정 정보를 요구하지 않습니다. 공식 사이트에는 광고 식별자, 분석 도구, 추적 쿠키가 없습니다.

3. 기기에 저장되는 정보

앱을 사용하면 다음 정보가 기본적으로 사용자의 컴퓨터에 있는 ~/.blank 폴더에 저장됩니다.

  • 설정과 프로바이더 키: config.json
  • 대화 세션, 메모리, 스킬, 체크포인트
  • 생성한 미디어와 Paper 문서
  • 실행 로그와 자동화 기록

키는 저장 후 화면에 전체 값이 다시 표시되지 않고 마스킹됩니다. BLANK_HOME 환경 변수로 데이터 위치를 바꿀 수 있으며, 폴더를 삭제하면 해당 데이터가 함께 삭제됩니다.

4. 외부로 전송되는 정보

blank 자체는 대화를 자체 서버로 보내지 않습니다. 다만 사용자가 선택하거나 설정한 모델 프로바이더, 검색 API, MCP 서버, 미디어 엔진, SSH 대상에는 작업에 필요한 프롬프트, 첨부 파일, 도구 결과가 전송될 수 있습니다. 이 정보는 각 제공자의 개인정보처리방침과 보관 정책을 따릅니다.

설치 파일은 GitHub Releases에서, 사이트는 GitHub Pages에서 제공됩니다. GitHub는 접속 시 IP 주소, 브라우저 정보, 요청 시각 등 일반적인 서버 로그를 처리할 수 있습니다. 자세한 내용은 GitHub의 개인정보처리방침을 확인하세요.

5. 사이트의 로컬 저장소

공식 사이트는 최신 릴리스 정보를 sessionStorage에 최대 10분 동안 임시 저장합니다. 이 값은 다운로드 버튼을 빠르게 표시하기 위한 것으로, 탭을 닫으면 사라지며 서버로 전송되지 않습니다.

6. 보관과 삭제

로컬 데이터는 사용자가 직접 삭제할 때까지 기기에 남습니다. 앱의 데이터 폴더를 열어 세션, 미디어, 설정을 개별적으로 지울 수 있습니다. 앱을 제거해도 ~/.blank 폴더는 자동으로 삭제되지 않습니다.

7. 아동과 청소년

blank는 계정을 만들지 않고 이름, 이메일, 전화번호, 생년월일 같은 개인정보를 수집하지 않습니다. 개인정보를 입력하는 절차가 없으므로 만 14세 미만 사용자도 별도의 보호자 동의 없이 앱과 사이트를 사용할 수 있습니다. 앱의 대화와 설정은 사용자의 기기에 저장됩니다.

사용자가 연결한 모델, 검색, MCP 제공자의 이용 조건과 연령 정책은 각 제공자를 따릅니다. 미성년자가 사용할 때는 보호자가 설정과 사용 범위를 함께 확인하는 것을 권장합니다.

8. 외부 링크

사이트와 앱에는 GitHub, 모델 프로바이더, 기타 외부 서비스로 이동하는 링크가 있을 수 있습니다. 외부 사이트의 정보 처리 방식에는 이 방침이 적용되지 않습니다.

9. 방침의 변경

기능이나 법령이 바뀌면 이 방침을 수정할 수 있습니다. 중요한 변경은 이 페이지에 시행일과 함께 게시합니다.

10. 문의

개인정보 처리에 관한 문의는 GitHub Issues로 남겨 주세요.
