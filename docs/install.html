Windows

Windows 10 이상 · x64 · 설치 파일

v1.3.2
설치 파일 받기 최신 릴리스 확인 중… ↓

GitHub Releases에서 직접 내려받습니다.

  1. 1

    설치 파일 실행

    다운로드 폴더에서 설치 파일을 엽니다. Windows가 변경을 허용할지 물으면 ‘예’를 선택합니다.

  2. 2

    SmartScreen 한 번 통과

    ‘Windows에서 PC를 보호했습니다’가 뜨면 추가 정보를 누르고, 이어서 실행을 누릅니다. 아직 서명 전이라 한 번 표시되는 경고입니다.

    !Windows에서 PC를 보호했습니다

    Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.

    실행 안 함 추가 정보 실행
  3. 3

    설치를 마치고 blank 열기

    기본 설치 위치 그대로 마치고 시작 메뉴에서 blank를 엽니다. 이전 blank 창이 열려 있으면 먼저 완전히 닫습니다.

경고가 뜨는 이유

현재 Windows 설치 파일은 아직 코드 서명 전입니다. SignPath Foundation 심사가 끝나면 서명된 빌드로 바뀝니다. SmartScreen을 끄거나 제외 항목에 추가하지 마세요. 이 페이지와 GitHub Actions에서 만든 파일만 받으면 됩니다. 코드 서명 정책

Intel Mac 빌드
  1. 1

    디스크 이미지 내려받기

    Mac에 맞춰 Apple silicon 또는 Intel 빌드를 고릅니다. 이 기기에 맞는 빌드가 먼저 선택되어 있습니다.

  2. 2

    Applications로 옮기기

    .dmg를 열고 blank를 Applications 폴더로 끌어다 놓습니다.

  3. 3

    처음 한 번 열기

    Applications에서 blank를 엽니다. macOS가 확인할 수 없다고 하면 blank를 오른쪽 클릭하거나 Control-클릭해 열기를 고르고, 한 번 더 엽니다.

공증 전 빌드

macOS 빌드는 아직 공증되지 않았습니다. 그래도 열리지 않으면 시스템 설정 → 개인정보 보호 및 보안에서 허용하세요. 데이터는 ~/.blank에 남습니다.

Linux

Linux · x64 · AppImage

v1.3.2
AppImage 받기 최신 릴리스 확인 중… ↓

GitHub Releases에서 직접 내려받습니다.

  1. 1

    AppImage 내려받기

    AppImage는 파일 하나로 동작하며 별도 설치 프로그램이 필요 없습니다.

  2. 2

    실행 권한 주기

    터미널에서 내려받은 파일에 chmod +x를 실행합니다.

  3. 3

    blank 실행

    터미널에서 AppImage를 실행하거나, 파일 관리자가 허용하면 더블클릭합니다. 자동 업데이트는 AppImage를 직접 실행할 때 동작합니다.

업데이트와 데이터

업데이트는 GitHub 릴리스에서 제공되며 AppImage 파일을 그대로 두어야 합니다. 압축을 푼 빌드는 스스로 업데이트할 수 없습니다.

설치했는데도 계속 설치하라고 뜨나요?

설정 → 정보에서 실행 중인 버전을 확인하세요. 최신 릴리스보다 낮으면 임시 폴더의 예전 복사본이 열려 있을 수 있습니다. blank 창을 모두 닫고 시작 메뉴 또는 Applications에서 설치된 blank를 다시 엽니다. 설치 파일은 설치된 복사본만 바꾸며, 설치를 실행한 예전 창은 바뀌지 않습니다.
